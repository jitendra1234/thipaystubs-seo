Pay stubs are packed with short codes. Payroll systems use them to fit everything on one page, but they can make a simple paycheck hard to read. This guide explains the abbreviations you are most likely to see and where they appear on the stub.

## The basic sections

Most pay stubs follow the same layout:

1. **Header:** employer and employee details, pay period and pay date.
2. **Earnings:** what was earned this period, and the year-to-date total.
3. **Taxes:** federal, state and local taxes withheld.
4. **Deductions:** benefits, retirement contributions and other amounts taken out.
5. **Summary:** gross pay, total deductions and net pay.

## Earnings abbreviations

| Code | Meaning |
| --- | --- |
| **REG** | Regular hours or regular pay |
| **OT** | Overtime, usually paid at 1.5 × the regular rate |
| **DT** | Double time, required in some states for long shifts |
| **HOL** | Holiday pay |
| **PTO** | Paid time off taken this period |
| **SICK** | Paid sick leave taken |
| **BON** | Bonus |
| **COMM** | Commission |
| **RATE** | Hourly rate or salary rate for the line |
| **HRS** | Hours worked or paid |

## Tax abbreviations

| Code | Meaning |
| --- | --- |
| **FIT / FITW / FED** | Federal income tax withheld |
| **SS / OASDI / FICA-SS** | Social Security tax (Old-Age, Survivors and Disability Insurance), 6.2% |
| **MED / MEDI / FICA-MED** | Medicare tax, 1.45% |
| **FICA** | Social Security and Medicare combined |
| **SIT / SWT** | State income tax withheld |
| **LIT / LOCAL / CITY** | Local or city income tax |
| **SDI** | State Disability Insurance (for example California, New Jersey and New York) |
| **PFL / FLI** | Paid family leave insurance |
| **SUI** | State unemployment insurance (employee share in a few states) |

## Deduction abbreviations

| Code | Meaning |
| --- | --- |
| **401K / 403B** | Retirement plan contribution (pre-tax, unless marked Roth) |
| **ROTH** | Roth retirement contribution (after-tax) |
| **MED INS / DEN / VIS** | Medical, dental or vision insurance premium |
| **HSA** | Health Savings Account contribution |
| **FSA / DCFSA** | Flexible spending account, or dependent-care FSA |
| **LIFE / STD / LTD** | Life insurance, short-term or long-term disability insurance |
| **GARN** | Wage garnishment, such as child support |
| **UNION** | Union dues |

## Summary abbreviations

| Code | Meaning |
| --- | --- |
| **GROSS** | Total earnings before taxes and deductions |
| **NET** | Take-home pay after everything is withheld |
| **CUR / CURRENT** | Amount for this pay period |
| **YTD** | Year-to-date: the running total since January 1 |
| **EE / ER** | Employee / employer share |
| **DD / DIR DEP** | Direct deposit amount |

## Canadian pay stub codes

Canadian stubs use different taxes: **CPP** (Canada Pension Plan), **CPP2** (the second, enhanced CPP contribution on higher earnings), **EI** (Employment Insurance), **QPP** and **QPIP** in Quebec, and federal and provincial income tax. ## Why YTD matters

The year-to-date column is often the most useful part of a stub. It shows whether Social Security has reached the annual wage base, how much tax has been withheld so far, and it should match the totals on the employee's W-2 at the end of the year. If you're comparing it with year-end forms, see our guide to [W-2 vs 1099](/blog/w2-vs-1099).
